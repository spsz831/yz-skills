# AI杨侦探插图 Visual Profile v8.1

## 目的

全局风格只负责账号视觉身份、清晰度和文字安全；文章内容决定信息重点。现有 Profile 是常用参考，不是文章类型清单；遇到新题材时，可以组合、改写或新建 Profile，但必须继续遵守全局视觉基线。

默认渲染基线：

- 浅底编辑信息图解：标题、主体结构、短标签和结论或视觉收束构成稳定阅读层级
- 以文章内容为第一优先级，结构化图解、真实场景、人物、物件或抽象关系按段落需要选择
- 暖奶油白、墨绿、灰粉、铜棕
- 标题、对照、模块、流程与结论服务于内容；不默认使用电脑、桌面、工作台或中心设备
- 一张图只保留必要的标题、标签和结论；信息密度来自有效内容，不来自小字和装饰物件
- 全文插图统一文字系统：主标题使用现代中文杂志宋体/人文宋体风格，副标题和正文标签使用清晰现代黑体/无衬线风格；同一张图不得混用书法体、卡通体、仿宋体和随机装饰字体
- 标题、标签和英文产品名保持固定层级：标题最大，副标题次之，模块标签最小但必须手机端可读；英文产品名使用干净的中性无衬线字体，除非确需官方 wordmark，不使用随机品牌字体
- 禁止模糊、旧化、假长文本、假引用和廉价 AI 科技风

### 色彩与物件角色

- 奶油白和墨绿是全局底色与结构色，不等于每张图只能有棕绿两色。
- 每张图按解释对象挑选一到两个低饱和强调色：信息、搜索、数据和连接用雾蓝；稳定工具、工作流和完成状态用鼠尾草绿；行动、决策和提醒用琥珀黄；创作、人物和对照用珊瑚粉。
- 颜色必须标识类别、路径或结果，不能只做背景渐变；单张图不要同时使用全部强调色。
- 需要图标时，优先使用带材料、动作和用途的轻 3D 物件；不需要时可以使用人物、空间、流程、数据关系或简洁抽象图形，不要以扁平贴纸图标凑信息量。

所有 Profile 共用上述视觉基线。Profile 不再引入第二套“叙事场景风”，只决定一张图更应解释事实、操作、工作流、判断或边界。字体规则跨文章、跨 Profile 统一，不随题材变化。

## Profile

### 新题材适配

文章类型不局限于下列 Profile。新增题材时，先写清楚这张图要帮助读者理解的一个核心问题，再从以下视觉方向中选择最合适的组合：

- 事实说明
- 人物或生活场景
- 工具和操作
- 机制和流程
- 分类和对比
- 数据和证据
- 历史、时间线和变化
- 观点、判断和行动建议

Profile 只是提示词规划时的参考标签，不是固定模板，也不要求每篇文章套用某一种版式。

### model-release

适用：模型发布、产品发布、能力更新。

- 产品入口、官网、发布会或展厅最多一张。
- 其他图片依次转向能力证据、真实任务验证、实际工作流、不同人群试用和个人判断。
- 不将品牌名、模型名、芯片或 logo 做成巨型广告主视觉。

### tool-tutorial

适用：工具介绍、安装、配置、功能和使用教程。

- 重点是用户操作、输入输出、关键设置、前后结果和常见问题。
- 允许清晰步骤关系，但每张图只讲一个操作节点。
- 屏幕可以更明确，但只放短标签、步骤名和结构化块。

### workflow-agent

适用：Agent、自动化、编码协作、工作流与权限边界。

- 重点是任务交接、工具调用、权限、失败恢复和协作结果。
- 用人、文件、终端、任务队列和结果面板表现关系。
- 不把工作流画成工厂管线、传送带或机械装置。

### trend-opinion

适用：行业趋势、就业、普通人判断、观察与观点文章。

- 重点是人的处境、选择、成本、压力、机会与结果。
- 产品品牌应退到背景，避免宣传化。
- 用具体生活或工作瞬间承接观点，避免纯抽象象征物。

### hands-on

适用：个人部署、实战经验、踩坑复盘、方法论。

- 重点是可复现的小任务、真实操作、前后变化和验证结果。
- 可以画工作台、终端、日志、文件和结果，但不生成无法核验的大段屏幕内容。
- 每张图必须让读者看出“我下一步可以怎么试”。

### technical-explainer

适用：RAG、PDF 解析、模型架构、数据处理、基础设施。

- 重点是数据、输入、处理、输出和边界条件。
- 使用真实文档、数据卡、检索结果、模型输入输出和简化结构关系。
- 允许结构化表达，但禁止重型模块板、工业流水线和机械工厂隐喻。

## 文章级 Visual Brief

每次插图规划生成 visual-brief.json，至少记录：

- profile：文章 Profile
- profile_source：用户指定或脚本自动推荐
- roles：每张图的叙事角色
- global_rules：跨文章视觉底线
- profile_rules：该 Profile 专用限制

Profile 自动推荐只是一项默认值。用户可以通过 -VisualProfile 覆盖。
