# AI杨侦探公众号封面风格

公众号封面是独立的叙事画面，不是正文 SVG 的裁切图，也不是信息图缩略版。目标是让读者一眼看见文章的核心情境或冲突，并与账号的原创角色和绘本式视觉语言保持一致。

本文件只补充项目内的封面使用与归档要求；通用生成流程和随 Skill 提供的角色素材以 `yang-cover` 为准。优先遵从用户当次要求，其次遵从本项目规范；修改共通规则时同步核对两处文档。

## 视觉方向

- 使用 AI杨侦探已认可的原创角色素材；保持人物脸型、五官、短黑发和黑色方框眼镜的辨识度。服装可根据选题与场景变化，黑色 T 恤是经典选项而非固定要求；用户指定服装时遵从。优先使用 `yang-cover` 自带角色图，按需参考本项目根目录下 `AI杨侦探角色素材/` 中适合公开使用的素材；不把个人原照片复制进发布包。
- 以完整场景讲故事：一个明确动作、一处环境和一件能代表文章议题的物件即可。角色应参与场景，而不是机械地站在标题旁。
- 暖白、森林绿和铜色可作为品牌色；按选题、情绪和服装选择蓝、紫、暖色或中性色，不固定绿底。保持清晰对比和有编辑感的原创卡通质感。
- 服装、动作、表情和位置随主题变化；服装简洁得体、与背景区分，避免品牌标识和繁复细节抢占视觉重点。
- 画面保留一个视觉焦点和清晰层次。默认使用简短醒目的大标题，位于背景前、人物头部后；可让头发或头部自然遮挡少量文字，但标题仍须可辨，脸和眼镜保持清晰。使用用户给定的准确短标题；未给出时依据文章提炼。不生成小字、长副标题或伪文字。用户指定布局时遵从。参考案例只学习层次与构图，不复制具体画面。
- 封面要表达文章独有的问题、反差或结果。避免泛化的机器人、发光芯片、代码雨、仪表盘，也不要直接复刻参考文章的人物、插画或版式。

## 尺寸与版式

- 默认分别交付两张独立图片：左侧用途的 `2.25:1` 横图和右侧用途的 `1:1` 方图，示例像素分别为 `2250×1000`、`1000×1000`。两图分别保持完整构图，角色与风格协调；核对实际尺寸和比例，不要求从同一张整图裁切。
- 只有用户需要博客、社交平台或其他横版渠道素材时，才额外制作 `16:9` 版本；调整构图适配比例，不简单拉伸或粗暴裁切主封面。
- 生成前先写一句封面意图：`读者看到什么场景，场景如何代表文章的核心问题`。用它检查画面是否传达选题，而非只检查是否好看。

## 交付与验收

- 使用 `yang-cover` 制作封面；将成图和实际使用的提示词或可编辑源稿归档在 `reports\gzhrb\publish-units\<article-id>\covers\`。若复用用户素材，标注来源。
- 检查实际宽高比例、清晰度、标题拼写、角色一致性、主体裁切和手机缩略图可辨识度。若图内文字变形或不可读，优先调整并重新生成；若采用后续排版，须使用当前环境允许的编辑方式并核对成品，不得声称文字已准确而未检查。
- 封面是发布支持素材，不替代博客 Markdown 或公众号 SVG 完整代码。记录本地文件路径；未导入公众号并预览时，不声称平台显示效果已验证。
