# AI杨侦探默认配图风格

本规范用于博客 Markdown 等文章中的独立解释型配图。公众号 SVG 的连续角色场景遵循 `wechat-svg.md`，文章封面遵循 `cover-style.md` 与 `yang-cover`；不要把本规范里的编辑图解基线套用到这两类成品。

Default style is the current repository-defined `AI杨侦探浅底编辑图解风`.

Required visual direction:

- `70%` structured editorial explainer plus `30%` light 3D objects with premium print-like texture: use a clear hierarchy, comparison, framework, process, or conclusion; do not default to a human narrative scene
- warm cream base plus two to three low-contrast gray-pink / copper-brown color fields, premium print-like texture, and a restrained editorial plane; use a corner paper, notebook edge, or tabletop when needed to avoid an empty background, but avoid strong grain, haze, distressed vintage effects, retro machinery and exposed pipes
- crisp deep-green outlines, sharp object edges, clean solid fills, concise labels, and mobile-width legibility
- four to nine short Chinese labels for inputs, outputs, states, abilities, or key numbers; use one concise image title or short conclusion when it improves comprehension, but no article heading, paragraph, or slogan
- keep cream and deep green as the account base, then assign one or two restrained semantic accents to categories or key paths: muted blue for information and connection, sage for stable tools and completion, amber for action and decision, coral for creation and contrast; never use all accents as a rainbow palette
- use compact task objects with recognizable action and material rather than flat generic icons: e.g. editor plus files, extension module, terminal, source stack under magnifier, spreadsheet-and-calendar, endpoint connector, or creative tool
- premium and clean, but low AI feel
- avoid dark blue, dark purple, neon, cyber-tech visual language
- select the composition that matches the section: centered framework, balanced comparison, ordered flow, or focused object scene; grouped grids, comparison panels, concise cards, and flow arrows are allowed when they explain the article and retain clear hierarchy
- avoid generic dashboards, SaaS onboarding pages, no-order card walls, repeated three-column comparisons with no hierarchy, dense small-text panels, copy-pasted template layouts and decorative clutter
- select a Visual Profile before planning: model-release, tool-tutorial, workflow-agent, trend-opinion, hands-on, or technical-explainer. Profiles determine content emphasis only; every Profile shares the same editorial-explainer baseline
- use one concise title and three to eight verifiable short labels. Never generate large prose, citations, formulas, fake UI copy, or dense unreadable text

Default image settings:

- aspect ratio: `16:9`
- quality: `2K`

Default palette anchors:

- `#F6F1E8`
- `#27403A`
- `#D8BFC5`
- `#A56A43`
