# AI杨侦探开头诊断与改写

适用于本账号的文章写作、全文优化或用户要求修改开头。融入原有写作与综合审校，不单独设置阶段、评分或确认。用户指定开头、文章类型和事实准确性优先。

## 先找到有吸引力的真实切口

- 通读已有素材及前几段，找可核实的具体情境、动作、关键事实或数据；若更好的切口藏在后文，优先前移，再补必要背景。实操体验可先呈现真实问题与动作；新闻文章要尽早交代具体事件、来源和关键数字，不为“先场景”延误或删去理解事件所必需的信息。
- 按素材选择切法，不强套模板：具体场景与结果、关键数据与其意义、判断如何改变、具体时刻与动作。转折、反差或悬念只有在内容真实且有价值时使用；无需每篇都有转折词。
- 不虚构用户的经历、时间、感受、实测结果或数字；缺少亲身经历就从可核实事实、读者问题或明确的分析切入。数字说明来源、范围和必要条件，不为冲击力夸大。

## 判定并直接修正

定位标题与摘要后的正文首段，连同前 3 段一起检查；引用块如果实际承担正文开头，也纳入检查。

1. **读者能否理解发生了什么、与自己有什么关系？** 若全是空泛背景、术语或堆砌产品名，前移真实情境或关键事实，首次必要术语用简短人话解释。
2. **有没有值得继续读的具体内容？** 若连续堆疑问句、重复痛点或平铺背景而没有明确问题、发现或价值，合并并重写。具体切口可以是行动、事实、关键数字或清楚的判断，不要求机械包含日期、数字或反转信号词。
3. **来源和时间是否真正帮助理解？** 单纯交代写作过程、网页署名日期等元信息可后移或删除；与时效、归因或准确性有关的来源、日期和限定必须保留并恰当放在前文，不因出现“官网”或“根据资料”自动删除。
4. **首段是否拥挤？** 超过约 100 个汉字时优先检查能否拆分、删去重复；这是提示而非硬上限，不凭字数自动判失败。
5. **语义和证据是否仍然成立？** 把改写后的结论、数据、来源与原素材对照，保留必要条件，区分作者亲测、官方说明和推断。

发现问题时直接改写首段及必要的衔接，完成后检查读起来是否自然；仅在用户要求审稿或解释时列出问题与理由，不要求用户自己完成改写。不要虚构公众号首屏固定行数、点击率或传播效果。
