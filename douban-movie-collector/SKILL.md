# douban-movie-collector

当前版本：`1.2.2`

本版本新增媒体类型配色校验：新增、更新和历史修复都按「媒体类型」重新设置行底色，不再继承上一条记录的颜色。

将电影和电视剧整理到现有 xlsx 收藏表。用户说“收藏电影”“收藏电视剧”“录入影视”“修改网盘链接”“补全评分”时触发。

## 目标表格

正式收藏表只有一个，固定使用：

`C:/Users/zhen/.codex/skills/douban-movie-collector/examples/2026-09-04_电影资源收藏表.xlsx`

这是唯一权威模板和长期数据文件。用户没有明确指定其他文件时，所有新增、更新、补全和排版操作都必须写入这个文件；不得新建收藏表、复制成 `_new.xlsx`、使用工作区中其他相似文件或另存为临时版本。文件不存在或无法写入时停止并提示用户，不要自行创建替代文件。只有用户明确指定了另一份 xlsx，才允许使用用户指定的文件。

按媒体类型使用两个工作表：

- `电影收藏`：只放电影。
- `电视剧收藏`：放电视剧和迷你剧；二者仍通过「媒体类型」列区分。

两个工作表共用基础列、筛选和冻结首行设置。整行底色由媒体类型决定，不继承上一条记录的颜色：

- `电影`：浅蓝色
- `电视剧`：浅蓝色
- `迷你剧`：淡紫色
- `综艺`：浅橙色
- `纪录片`：淡黄色

「观看状态」单元格单独使用状态色，不覆盖整行媒体类型色：`想看` 浅蓝、`已看` 浅绿、`弃看` 浅灰、`重看` 浅橙。

- `电影收藏` 不设置「集数」「季数」列；电影录入时不填写这两个字段。
- `电视剧收藏` 保留「集数」「季数」列，用于记录电视剧和迷你剧的集数、季数。
- 「观看状态」支持 `想看 / 已看 / 弃看 / 重看`，使用下拉选择；状态单元格分别使用浅蓝、浅绿、浅灰、浅橙标记，并保留工作表筛选。

当前表格列顺序为：

`电影收藏` 列顺序：

`序号 / 媒体类型 / 电影名称 / 国家/地区 / 年份 / 类型 / 导演 / 豆瓣评分 / 观看状态 / 收藏日期 / 网盘链接 / 提取码 / 豆瓣ID / 豆瓣链接 / 评分核验日期 / 备注`

`电视剧收藏` 列顺序：

`序号 / 媒体类型 / 电影名称 / 国家/地区 / 年份 / 类型 / 导演 / 豆瓣评分 / 集数 / 季数 / 观看状态 / 收藏日期 / 网盘链接 / 网盘链接2 / 提取码 / 豆瓣ID / 豆瓣链接 / 评分核验日期 / 备注`

新录入内容必须写入对应工作表；不要另建表或另存副本。序号在各工作表内分别连续递增。

## 工作流

### 0. 常用维护命令

换电脑首次初始化：

```powershell
$py = 'python'
$setup = '<Codex skills目录>/douban-movie-collector/scripts/setup_movie_collection.py'
& $py $setup
```

初始化脚本会自动识别 `CODEX_HOME` 和当前用户目录，下载公开 skill，克隆私有 `movie-collection`，并把最新收藏表放入本机 skill 的 `examples` 目录。已有目录只更新 skill 文件，不删除其他用户文件。需要先登录 GitHub，并确保当前账号有私有仓库访问权限。也可以用 `--skills-dir` 和 `--collection-dir` 指定路径。

数据审计：

```powershell
$py = 'C:/Users/zhen/.workbuddy/binaries/python/envs/default/Scripts/python.exe'
$audit = 'C:/Users/zhen/.codex/skills/douban-movie-collector/scripts/audit_movie_collection.py'
& $py $audit --xlsx 'C:/Users/zhen/.codex/skills/douban-movie-collector/examples/2026-09-04_电影资源收藏表.xlsx' --check-links
```

审计会报告重复片名、缺少评分、缺少网盘/豆瓣链接、缺少集数/季数、格式错误链接和无法访问的链接。`--check-links` 会实际访问链接，网络波动时以报告为准，不要据此自动删除条目。

同步到个人观影私有仓库：

```powershell
$py = 'C:/Users/zhen/.workbuddy/binaries/python/envs/default/Scripts/python.exe'
$sync = 'C:/Users/zhen/.codex/skills/douban-movie-collector/scripts/sync_movie_collection.py'
& $py $sync
```

同步命令会自动定位正式收藏表和 `movie-collection` 仓库，也支持 `--xlsx`、`--repo` 显式指定路径。提交前检查本地仓库是否干净；若有未提交修改会停止，不覆盖用户内容。skill 本身继续保存在 `spsz831/yz-skills`，与个人收藏表分开维护。

### 1. 解析与版本确认

从消息中提取：名称、年份、网盘链接、提取码、用户提供的评分和版本描述。

- 电影默认 `媒体类型=电影`。
- 有“电视剧/韩剧/国剧/全 N 集/迷你剧”等字样时，设为 `电视剧` 或 `迷你剧`，并填写集数。
- 未指定 `--sheet` 时，脚本按媒体类型自动选择工作表；一批数据不要混合电影和电视剧，混合批次应拆成两批。
- 同名或信息冲突时，先列出候选版本，让用户确认；不要凭标题猜测。
- 电视剧或迷你剧存在季数时填写 `季数`；只有总集数时只填写 `集数`。电影不填写集数和季数。
- `status` 只允许 `想看`、`已看`、`弃看`、`重看`；未提供时默认 `想看`。

### 2. 信息核对

联网核对优先使用豆瓣条目；所有联网操作遵循 `web-access` Skill。

核对字段：年份、媒体类型、国家/地区、类型、导演、豆瓣评分、豆瓣 ID、豆瓣链接和一句话简介。

评分规则：

- 用户明确提供评分时可直接采用，并仍记录评分核验日期。
- 用户未提供评分时，从当前豆瓣条目读取。
- 豆瓣页面不可直接读取时，用至少两个独立来源交叉核验；来源冲突时不要猜，向用户说明差异。
- 评分是动态数据，回报中说明“按核验当日记录”，但不要把来源或核验说明塞进备注。
- 评分必须是 0–10 的数字；导演、年份、豆瓣 ID 不确定时留空，不编造。

### 3. 备注规范

备注只写不超过 120 字的剧情简介：

- 不写“豆瓣评分”“评分待核对”“来源于搜索”等元信息。
- 不重复写 1080P、4K、字幕、蓝光、夸克等资源描述。
- 不剧透结局；电视剧可在末尾写“全 N 集”。
- 使用脚本的 `strip_source_tags()` 做最后清洗。

### 4. 查重、追加与更新

使用脚本：

```powershell
$py = 'C:/Users/zhen/.workbuddy/binaries/python/envs/default/Scripts/python.exe'
$script = 'C:/Users/zhen/.codex/skills/douban-movie-collector/scripts/append_movie.py'
& $py $script --xlsx '<表格绝对路径>' --json '[{"name":"片名","media_type":"电影","link":"https://pan.xxx/s/id","code":"abcd","year":2024,"country":"中国大陆","genre":"剧情","director":"导演","rating":8.1,"douban_id":"1234567","douban_url":"https://movie.douban.com/subject/1234567/","remark":"剧情简介"}]'
```

未收到用户指定的其他文件时，`<表格绝对路径>` 必须使用上面的正式收藏表路径。

查重与更新规则：

- 提供豆瓣 ID 时，只按豆瓣 ID 定位，不因片名相同而误更新其他版本。
- 未提供豆瓣 ID 时，先按规范化片名筛选；若同名只有一条，可继续处理；若有多条，则再用年份和媒体类型缩小范围。
- 仍有多个候选时必须跳过并报告，请用户补充豆瓣 ID、年份或媒体类型，不要猜测。
- 默认重复时跳过并报告所在行；确认要修改已有条目时使用 `--update`，只覆盖 JSON 中非空字段，例如修正链接：

```powershell
& $py $script --xlsx '<表格绝对路径>' --update --json '[{"name":"片名","link":"https://pan.quark.cn/s/new"}]'
```

只有用户明确要求重复收藏时才使用 `--force`。不要为了绕过查重使用 `--force`。

脚本行为：

- 序号自动顺延；状态默认“想看”；收藏日期默认今天。
- 自动复制上一条数据行的样式。
- 新增或更新「网盘链接」「网盘链接2」「豆瓣链接」时，使用 Excel 原生超链接；显示为“打开网盘”“打开网盘2”“打开豆瓣”，不要把完整网址作为展示文本。
- 按目标工作表和媒体类型应用固定行底色，并自动更新该工作表的筛选范围。
- 每次写入前会重新校正已有记录的媒体类型行底色；新增和更新记录也会按媒体类型套用颜色，禁止从上一行继承颜色。
- 原子保存，写入前先生成同目录临时文件；目标文件被占用时返回 `LOCKED`，不生成容易混淆的 `_new.xlsx`。
- 写入完成后重新读取目标文件并复核写入行；收到 `LOCKED` 时只提示用户关闭 Excel/预览后重试。
- 支持 `--no-schema` 禁止自动追加可选列。

## 回报格式

简要回报：写入行号、名称、媒体类型、年份、评分、集数、状态；更新时说明更新了哪些字段；跳过时说明重复原因；评分按核验当日记录。

## 边界

- 不擅自删除、覆盖其他收藏或创建第二个长期使用的表格。
- 正式收藏表是唯一数据源；不要新建、另存或切换到其他收藏表。
- 不修改已有条目，除非用户明确要求更新或修正。
- 用户提供的第一个网盘链接写入「网盘链接」，第二个写入「网盘链接2」；两个链接均使用可点击的 Excel 原生超链接，提取码只写入提取码列。
- 资源链接属于用户数据，不在回报中重复展开或传播到备注。

## 数据验证

完成后至少验证：目标文件存在、名称只出现预期次数、网盘链接准确、评分为有效数字、剧集集数正确、备注不含片源标签。修改链接或评分时，重新读取目标行确认写入结果；涉及链接时还要验证目标单元格存在原生超链接地址，不能只检查显示文字。
