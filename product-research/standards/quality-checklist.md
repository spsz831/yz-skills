# 质量检查清单

## 检查时机

1. **生成初稿后**：基础检查
2. **逐章审查后**：内容检查
3. **最终交付前**：完整检查

## 检查清单

### 一、结构完整性

- [ ] 所有章节都有实质内容
- [ ] 章节顺序符合模板要求
- [ ] 标题层级正确（一级、二级、三级）
- [ ] 无空白章节
- [ ] 附录完整（数据来源、术语表等）

### 二、内容质量

- [ ] 所有数据标注来源
- [ ] 关键数据交叉验证（至少2个来源）
- [ ] 无 ⚠️ 占位符
- [ ] 无"待补充"、"TODO"等标记
- [ ] 引用准确（来源与内容匹配）

### 三、数据准确性

- [ ] 数字准确（价格、用户数、融资等）
- [ ] 日期准确（上线时间、更新时间）
- [ ] 名称准确（产品名、公司名、人名）
- [ ] 链接有效（官网、文档、参考链接）

### 四、来源标注

- [ ] 每段内容标注来源
- [ ] 来源格式统一（如：`(来源: libtv-01-official.md)`）
- [ ] 第三方来源标注可信度
- [ ] 竞品评测标注利益关系

### 五、交叉验证

**需要交叉验证的关键数据**：
- [ ] 定价方案
- [ ] 用户规模
- [ ] 融资金额
- [ ] 技术参数
- [ ] 市场份额

**验证方法**：
- [ ] 至少2个独立来源确认
- [ ] 优先选择官方来源
- [ ] 冲突数据标注说明

### 六、文件规范

- [ ] 文件名符合命名规范
- [ ] 素材归档到 workspace
- [ ] 截图保存到 images
- [ ] 临时文件已清理

### 七、格式规范

- [ ] 表格格式正确
- [ ] 列表格式统一
- [ ] 代码块格式正确
- [ ] 链接格式正确
- [ ] 标点符号规范

### 八、可读性

- [ ] 语言流畅
- [ ] 逻辑清晰
- [ ] 无错别字
- [ ] 术语使用一致
- [ ] 表达客观中立

### 九、时效性

- [ ] 标注调研日期
- [ ] 标注数据来源日期
- [ ] 检查信息是否过时
- [ ] 需要时标注"截至{日期}"

### 十、完整性

**产品调研报告**（11章）：
- [ ] 一、产品概述
- [ ] 二、核心功能
- [ ] 三、使用方式
- [ ] 四、定价方案
- [ ] 五、应用场景
- [ ] 六、竞品对比
- [ ] 七、技术架构
- [ ] 八、产品生态
- [ ] 九、开发者API集成
- [ ] 十、用户评价与市场表现
- [ ] 十一、总结

**产品评测文章**（8节）：
- [ ] 一、引言
- [ ] 二、产品概述
- [ ] 三、核心功能体验
- [ ] 四、使用场景实战
- [ ] 五、优缺点分析
- [ ] 六、竞品对比
- [ ] 七、定价与性价比
- [ ] 八、总结与建议

**竞品对比分析**（6章）：
- [ ] 一、对比概述
- [ ] 二、功能对比
- [ ] 三、定价对比
- [ ] 四、技术架构对比
- [ ] 五、用户体验对比
- [ ] 六、综合评价与建议

## 检查流程

### 第一步：快速浏览

1. 通读全文
2. 标记明显问题
3. 检查整体结构

### 第二步：逐章检查

1. 按章节逐一检查
2. 对照原始素材验证
3. 补充缺失内容

### 第三步：数据验证

1. 提取所有关键数据
2. 逐一验证来源
3. 交叉验证重要数据

### 第四步：格式检查

1. 检查表格、列表格式
2. 检查链接有效性
3. 检查标点符号

### 第五步：最终确认

1. 再读一遍全文
2. 确认无明显错误
3. 确认符合交付标准

## 常见问题处理

### 问题1: 某些数据找不到第二来源

**处理**：
- 标注为"单源数据"
- 说明来源可信度
- 如有可能，补充间接证据

### 问题2: 不同来源数据冲突

**处理**：
- 优先选择官方来源
- 标注冲突数据
- 让读者自行判断

### 问题3: 某些章节内容单薄

**处理**：
- 补充深度调研内容
- 如果确实信息有限，说明原因
- 考虑调整章节权重

### 问题4: 发现明显错误

**处理**：
- 立即修正
- 追溯错误来源
- 检查是否有类似错误

## 检查工具

### 自动化检查

```bash
# 检查占位符
grep -r "⚠️" *.md
grep -r "待补充" *.md
grep -r "TODO" *.md

# 检查来源标注
grep -r "来源:" *.md | wc -l

# 检查文件命名
ls -1 | grep -E "^[a-z]+-[a-z]+\.md$"
```
