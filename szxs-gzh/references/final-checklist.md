# szxs-gzh final-checklist

在进入最终 Markdown 与播客阶段前，必须检查：

## 一、公众号最终 Markdown
- 开场白完整，符合四知公众号风格
- 日期、公历农历、干支、星期、星座信息完整
- 每日生肖总览包含：特吉 / 次吉 / 需要注意
- **12 生肖正文按当天运势高低排序**
- 生肖正文不是固定生肖顺序时，也必须保证排序逻辑清晰
- Markdown 标题层级、代码块、换行和列表格式正确
- 彭祖百忌内容与解释完整
- 十二建星名称、性质（黄道 / 黑道）与说明正确
- 每日宜忌完整
- 每日宜忌优先取自 `https://mobile.51wnl-cq.com/huangli_tab_h5/` 顶部主卡片，而不是“吉日查询”扩展列表
- 招财穿衣、搭配色、神位方位、吉时完整
- 若当天地支属于子/丑/寅/卯/辰/巳/午/未/申/酉/戌/亥之一，`择吉趋吉` 中的穿衣、搭配、相合生肖、桃花生肖、吉时必须匹配固定映射
- `招财穿衣` 与 `吉祥搭配` 的第一个颜色已带颜色 emoji
- `相合生肖` 与 `桃花生肖` 后面的生肖已带对应 emoji
- 方位类字段仍按当天真实黄历数据填写，没有被固定映射误覆盖
- 每日吉时写出具体时段
- 避讳方位与口诀对应当日地支
- 今日推荐电影已替换
- 经典台词已替换
- 若用户未单独指定电影，则电影名称、年份与台词已按 `cikeee.cc/wangri` 的“文章日期往前推 10 天”规则取值
- 电影图片 URL 已替换
- 最终内容可以直接保存为完整 Markdown
- 四知文章口吻已校准：有一点神秘感与仪式感，但不故作高深
- 文案没有明显模板腔、鸡汤腔、短视频口号腔

## 二、播客文案生成前
- 必须以“最终正确 Markdown”为唯一输入
- 不得使用初稿或未修正稿生成播客
- 播客中需覆盖全部 12 个生肖
- 播客中需完整播报最终稿中的全部吉时时段
- 播客中的吉时必须与最终 Markdown 原始吉时一致
- **只允许把吉时改写成口播友好表述，不允许改动吉时数据**
- 播客中需解释避讳方位口诀
- 播客语气需适合双人音频口播
- 四知口吻稳、清、有余味，不说教、不卖弄
- 一宜提问自然，不夸张、不喧宾夺主
- 播客最后一句必须固定为：**咱们明儿个见。晚安。**
