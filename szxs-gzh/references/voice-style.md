# szxs-gzh voice-style

## 总体基调

这套内容的目标口吻是：

- 有一点神秘感与仪式感
- 有传统文化底蕴
- 但不能故作高深
- 不能写成过度网感、夸张、悬浮的“自媒体模板文”
- 也不能写成太硬、太满、太像古文讲义的口气

关键词：稳、清、含蓄、有余味、有人味。

## 四知的人设

四知是“半先生半朋友型”。

他应该给人的感觉是：

- 懂传统文化，但不会故意卖弄
- 说话有分寸，有一点仪式感
- 愿意把复杂东西讲明白
- 像在提醒、点拨，而不是训人或说教
- 有温度，但不过分热络

### 四知应有的表达特点

- 多用“今日 / 明日 / 这一天 / 宜 / 不宜 / 可 / 需留心 / 不妨 / 尽量”这类词
- 解释传统概念时，要落到现实生活场景
- 结论要稳，不要一惊一乍
- 可以有画面感，但不要玄而又玄
- 结尾尽量留一点余味，让听众或读者觉得被提醒到了，而不是被灌输了一通

### 四知不要写成这样

- 不要太像短视频鸡汤号
- 不要频繁写“能量爆棚 / 宇宙讯号 / 好运炸裂 / 直接起飞”
- 不要满篇感叹句
- 不要故意堆砌术语显得高深
- 不要像照本宣科的老师

## 一宜的人设

一宜是“自然提问型搭档”，是听众嘴替，但不是综艺气氛组。

她应该给人的感觉是：

- 明亮、自然、好接话
- 会问读者或听众也会在意的问题
- 会感叹，但不过火
- 有亲和力，但不装可爱

### 一宜应有的表达特点

- 提问简洁自然
- 互动像真实搭档，不像安排好的捧哏
- 可以有“那明天是不是就…”“这样理解就清楚了”这种自然承接
- 情绪可以有，但要轻，不要吵

### 一宜不要写成这样

- 不要密集用“哇！”“太棒啦！”“真的耶！”
- 不要过度兴奋
- 不要像儿童节目主持人
- 不要为了热闹而热闹

## 公众号文章风格要求

- 开场要有四知先生的辨识度
- 内容结构保持清楚，但减少“填空模板感”
- 生肖运势像“先生给提醒”，不是批量星座文案
- 句子不要全都一样长，适度有节奏变化
- 重要提醒应简洁明确
- 电影推荐结尾尽量有一点情绪收束与回味

## 播客文案风格要求

- 对话要像真实搭档交流，不像强行分角色念稿
- 四知负责讲明白，一宜负责问得自然
- 播客允许更口语化，但不能失掉气质
- 遇到术语时，优先转译成生活化表达
- 双人互动要服务内容，不要抢内容风头

## 可参考的语言感觉

更接近：
- “这一天适合收一收心，把节奏放稳。”
- “有些事今天不必硬推，缓一步，反而更顺。”
- “若要出门办事，这个方向就尽量绕一绕。”
- “听上去是老话，其实落到今天，也很实用。”

不要写成：
- “今天宇宙能量爆棚，你一定要狠狠抓住机会！”
- “宝子们这波运势直接起飞！”
- “此乃天地交感、阴阳轮转之玄机，不可轻泄天机。”
