# x-spsz — X 平台个人深度解读卡片生成器

## 1. 这个 Skill 解决什么问题

把一段文字素材(采访/新闻稿/演讲/两个时间点对比/任何个人想解读的内容)整理成**一张**可以直接发在 X (Twitter) 平台的中文深度解读卡片。

- **不是**:海报、壁纸、产品宣传图、纯摘要搬运
- **是**:有作者独立判断、有原文/意译标注、有金句收束的个人自媒体卡

## 2. 适用范围 / 何时启用

- 用户提供了一段素材并要求"做成推特图 / 做成 X 图"
- 用户说"用 x-spsz"、"做张 spsz 图"、"深度解读卡片"
- 用户明确指定 GPT Image 2 或 OpenAI 4K 生图
- **不适用**:产品海报、人物介绍卡、纯资讯卡片(没"我的判断")、英文/日文等其他语言

## 3. 核心约束(写死不可改)

### 3.1 落款:只放 @spsz0831

- 不写 slogan(已否决所有 slogan 方案:看大佬调档 / 一家之言 / 个人整理 等)
- 卡片底部右下角,极小字号,**只放 `@spsz0831`**

### 3.2 主标题:必须有自己的钩子

- 不是"素材原文摘要"
- 必须有钩住读者的视角/对比/反差
- 表达作者自己的解读入口

### 3.3 我的判断:必须有,而且至少 3 行

- 不是"原文摘要",是"原文 + 我怎么看"
- 每条证据必须标 [原文] 或 [意译],防止搬运感
- 这是自媒体卡,不是资讯卡

### 3.4 收束金句:必须自己写

- 不能直接引用素材原话
- 必须有反转 / 重音 / 出人意料

### 3.5 工具固定:OpenAI GPT Image 2 + 3:4 + 4K

- **模型**:OpenAI GPT Image 2(2025-2026 最新,**不是** DALL·E 3、**不是** gpt-image-1)
- **比例**:3:4 (3072 × 4096 像素)
- **质量**:4K, ultra high definition, PNG
- **工具入口**:ChatGPT 最新网页端
- **prompt 前缀**:本 Skill 内置,无需用户手写(见 §6)

## 4. 卡片版式:9 段结构

```
┌────────────────────────────────────────┐
│ 1. 眉题(小字、淡色)                    │
│                                        │
│ 2. 主标题(超大、加粗、对比钩子)        │
│                                        │
│ 3. 副标题(一句话语境说明)              │
│                                        │
│ 4. 证据块 1 [原文/意译](带原文出处)    │
│                                        │
│ 5. 证据块 2 [原文/意译](带原文出处)    │
│                                        │
│ 6. 我的判断(≥ 3 行,带项目符号)        │
│                                        │
│ 7. 收束金句(自写,有反转)              │
│                                        │
│ 8. 大面积留白                           │
│                                        │
│ 9. @spsz0831(极小、右下角)             │
└────────────────────────────────────────┘
```

## 5. 视觉规范

### 5.1 配色(写死)

| 用途 | 颜色 | Hex |
|---|---|---|
| 背景 | 极深黑 | `#0A0A0F` |
| 主标题 / 金句 | 暖金 | `#C9A961` |
| 副标题 / 证据块小标 | 亮蓝 | `#1A4FFF` |
| 正文 | 白 | `#FFFFFF` |
| 次要说明 | 浅灰 | `#9CA3AF` |
| 辅助 | 深灰 | `#6B7280` |

### 5.2 字体(中文)

- 主标题/金句:思源宋体 Heavy / Noto Serif SC Black
- 正文:思源黑体 / Noto Sans SC
- 全部使用**全角中文标点**:，。、：；""「」——

### 5.3 字阶(基于 4K 输出)

| 元素 | 字号 |
|---|---|
| 主标题 | 310pt |
| 收束金句 | 215pt |
| 副标题 | 130pt |
| 眉题 | 88pt |
| 证据块标题 | 96pt |
| 证据块正文 | 70pt |
| 我的判断正文 | 72pt |
| @ID | 52pt |

### 5.4 留白

- 上下左右安全边距:≥ 180px (4K 下)
- 段间垂直间距:主标题 ↔ 副标题 ≥ 200px
- 证据块 1 ↔ 证据块 2 之间留 1 个空行
- 收束金句之下、@ID 之上留至少 400px 纯黑留白

(3072×4096 像素,4K 超清)的中文深度解读卡片。

- 这是个人自媒体深度解读卡,不是海报、不是资讯搬运、不是产品图

  我的判断 / 收束金句 / 大留白 / @spsz0831
- 必须用全角中文标点:，。、：；""「」——
- 主标题与收束金句必须有自己的钩子和反转,不能是素材原文

**用户只需要在 ChatGPT 端粘贴的内容** = 上面前缀 + 下文 prompt-template.md 里的卡片正文模板(填好内容)。

## 7. 执行流程

1. **收到用户素材**(采访 / 新闻 / 演讲 / 对比 / 任意素材)
2. **澄清两件事**:
   - 主标题怎么拟(钩子角度)
   - 我的判断怎么写(作者视角)
3. **生成卡片 9 段内容草稿**,每条证据标注 [原文] / [意译]
4. **走 checklist.md 全量自检**
5. **拼接 ChatGPT 端完整 prompt** = §6 前缀 + 正文模板 + 内容
6. **让用户复制到 ChatGPT 网页端生图**(本 Skill 不直接调用生图 API)
7. **如用户给出生成图,回查**:版式 / 标点 / 钩子 / 我的判断 / 落款是否到位

## 8. 调用模式

### 8.1 用户主动调用

- "用 x-spsz 帮我做张图"
- "做张推特深度解读卡"
- 直接说 "spsz 图"

### 8.2 本地命令调用

- `/x-spsz` (用户自定义 slash command,可后续补)
- 直接在对话中说 "用 x-spsz"

## 9. 关键原则

- **不搬运素材原话当主标题**:主标题必须重写
- **必须标注原文/意译**:防止误导读者以为你引用了原文
- **必须有作者判断**:这是自媒体,不是资讯
- **收束金句必须自己写**:不能引用
- **只放 @spsz0831**:不写任何 slogan
- **不直接调用生图**:ChatGPT 网页端是用户的工具,Skill 只负责产 prompt
- **失败要复盘**:生图失败 / 内容错位 → 更新 prompt-template.md
