# x-spsz — X 平台个人深度解读卡片生成器

## 1. 这个 Skill 解决什么问题

把一段文字素材（采访 / 新闻 / 演讲 / 时间点对比）整理成**一张**可以直接发在 X (Twitter) 平台的中文深度解读卡片 + **一段**可直接粘贴的短推文文案。

- **不是**: 海报、壁纸、产品宣传图、纯摘要搬运
- **是**: 有观点、有金句、信息密度控制得当的自媒体卡片

## 2. 适用范围 / 何时启用

- 用户提供了一段素材并要求"做成推特图 / 做成 X 图"
- 用户说"用 x-spsz"、"做张 spsz 图"、"深度解读卡片"
- 用户明确指定 GPT Image 2 或 OpenAI 4K 生图
- **不适用**: 纯资讯播报卡（没有观点）、人物介绍卡、英文/日文等其他语言

## 3. 核心约束(写死不可改)

### 3.1 落款：只放 @spsz0831
- 不写 slogan
- 卡片底部右下角，极小字号，**只放 `@spsz0831`**

### 3.2 主标题：必须有自己的钩子
- 不是素材原文摘要
- 必须有对比 / 反差 / 视角钩子
- ≤ 10 字（4K 下不溢出）

### 3.3 收束金句：必须自写
- 不能直接引用素材原话
- ≤ 14 字
- 有反转 / 重音 / 出人意料的落点
- 金句要口语化、通俗，不要文绉绉或绕弯子的表达

### 3.4 工具固定：ChatGPT GPT Image 2 + 3:4 + 4K
- **模型**：ChatGPT GPT Image 2（**不是** DALL·E 3、**不是** gpt-image-1）
- **比例**：3:4（3072 × 4096 像素）
- **质量**：4K, ultra high definition, PNG
- **工具入口**：ChatGPT 最新网页端
- **prompt 前缀**：本 Skill 内置，无需用户手写（见 §6）

## 4. 卡片版式：5 段结构

```
┌──────────────────────────────────┐
│ 1. 眉题（小字、深灰）              │
│                                  │
│ 2. 主标题（超大、深棕金、最醒目）  │
│                                  │
│ 3. 正文区块（1-3段短句，深灰色）   │
│    每段 ≤ 20 字                   │
│                                  │
│ 4. 收束金句（深棕金、有反转）      │
│                                  │
│ 5. @spsz0831（极小、右下角）       │
└──────────────────────────────────┘
```

**文字密度总则**：全卡总字数 **60-90 字**，控制在用户一屏能读完的范围内。

## 5. 视觉规范

### 5.1 配色(写死 — 浅色系)

| 用途 | 颜色 | Hex |
|---|---|---|
| 背景 | 米白暖色 | `#FAF6F0` |
| 主标题 / 金句 | 深棕金 | `#8B6914` |
| 正文 / 次要文字 | 深灰 | `#2D3436` |
| 眉题 / @ID | 中灰 | `#6B7280` |
| 辅助分隔线 | 浅金 | `#D1C4A9` |

### 5.2 字体(中文)

- 主标题 / 金句：思源宋体 Heavy / Noto Serif SC Black
- 正文：思源黑体 / Noto Sans SC
- 全部使用**全角中文标点**：，。、：；""「」——

### 5.3 字阶(基于 4K 输出)

| 元素 | 字号 |
|---|---|
| 主标题 | 310pt |
| 收束金句 | 215pt |
| 正文每段 | 72pt |
| 眉题 | 88pt |
| @ID | 52pt |

### 5.4 留白

- 上下左右安全边距 ≥ 180px
- 段间垂直间距 ≤ 80px（紧凑排列，不松散）
- 金句与 @ID 之间不留过多空白，紧凑贴合

## 6. 短推文文案（与卡片配合发布）

每张卡片生成后，**必须同步输出一段可直接发帖的短推文文案**（100 字内）。

要求：
- 不与卡片正文重复，而是补充一个观点或引发讨论的问题
- 可以带话题标签（#AI #DeepSeek 等）
- 语气口语化，像人在说话，不像机器播报

## 7. ChatGPT 端 prompt 前缀(已固化)

Skill 自动在用户的卡片内容前拼接以下前缀，直接拷贝到 ChatGPT 网页端对话框即可：

```
请使用 GPT Image 2 模型，严格按照下面的版式规范生成一张 3:4 比例
(3072×4096 像素，4K 超清)的中文深度解读卡片。

【生成前必读】
- 这是个人自媒体深度解读卡，不是海报、不是资讯搬运
- 必须包含 5 段结构：眉题 / 主标题 / 正文 / 收束金句 / @spsz0831
- 必须用全角中文标点：，。、：；""「」——
- 主标题 ≤ 10 字，金句 ≤ 14 字
- 正文每段 ≤ 20 字，最多 3 段，总字数 60-90 字
- 不写 slogan，不写"一家之言"、"个人整理"等落款文字
- 底部只放 @spsz0831，极小字号，右下角

【配色】
背景 #FAF6F0（米白），金 #8B6914（深棕金），正文 #2D3436（深灰），眉题/@ID #6B7280（中灰），分隔线 #D1C4A9（浅金）

【字阶(4K 输出)】
主标题 310pt，金句 215pt，正文 72pt，眉题 88pt，@ID 52pt

【生成后必做】
- 文字不能出现乱码、不能有方框 □
- 引号必须是中文""或「」，不是英文 ""
- 破折号必须是中文 ——，不是英文 --
- 不能出现溢出、裁切、字体重叠
- 【强制检查】确认背景是纯色实心米白，不是透明，不是白色，不是留白

【质量设置】
4K, ultra high definition, PNG, no watermark, SOLID BACKGROUND
```

**用户只需要在 ChatGPT 端粘贴的内容** = 上面前缀 + 下文 prompt-template.md 里的卡片正文模板（填好内容）。

## 8. 执行流程

1. **收到用户素材**（新闻 / 对比 / 任意素材）
2. **生成卡片 5 段内容草稿**：
   - 主标题（≤ 10 字，有钩子）
   - 正文（1-3 段短句，每段 ≤ 20 字）
   - 收束金句（≤ 14 字，有反转）
3. **生成短推文文案**（100 字内，口语化，可带话题标签）
4. **走 checklist.md 全量自检**
5. **拼接 ChatGPT 端完整 prompt** = §7 前缀 + 正文模板 + 内容
6. **让用户复制到 ChatGPT 网页端生图**（本 Skill 不直接调用生图 API）
7. **用户给出生成图后，回查**：版式 / 标点 / 钩子 / 落款是否到位

## 9. 调用模式

### 9.1 用户主动调用
- "用 x-spsz 帮我做张图"
- "做张推特深度解读卡"
- 直接说 "spsz 图"

### 9.2 本地命令调用
- `/x-spsz`（用户自定义 slash command，可后续补）
- 直接在对话中说 "用 x-spsz"

## 10. 关键原则

- **不搬运素材原话当主标题**：主标题必须重写，有视角钩子
- **不标注来源**：不需要 [原文] / [意译] 标注，避免搬运感
- **金句必须自写**：不能引用素材原话，要有反转或重音，口语化通俗
- **文字密度克制**：全卡 60-90 字，一屏可读
- **只放 @spsz0831**：不写任何 slogan
- **不直接调用生图**：ChatGPT 网页端是用户的工具，Skill 只负责产 prompt + 推文文案
- **失败要复盘**：生图失败 / 内容错位 → 更新 prompt-template.md 和 checklist

## 11. 相关文件
