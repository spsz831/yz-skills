# x-spsz 自检清单

## A. 事实与内容

- [ ] 时效性信息已核验，或明确标记为未核验
- [ ] 人物、公司、日期、数字和引语有来源或被谨慎表述
- [ ] 每个事件都有具体日期，格式为 `YYYY年M月D日`，例如 `2026年9月10日`
- [ ] 眉题没有只写“2026年9月”“近日”或“今天”
- [ ] 使用的是事件发生日或官方发布日期，而不是随手使用当前日期
- [ ] 多日事件使用明确日期范围；未知日期已标记待核实，未伪造具体日
- [ ] 已判断素材包含几个事件；无关事件已拆卡
- [ ] 已选择轻量卡、标准卡或深度卡
- [ ] 重要内容已区分事实、报道、观点和判断
- [ ] 事实、来源转述、作者判断和推测没有混在一起
- [ ] 主标题不是素材原句，有明确视角或反差
- [ ] 收束金句为自写，不冒充引语
- [ ] 轻量卡只保留必要信息，标准卡总文字量约 45–75 个中文字符
- [ ] 标准卡主标题 ≤10 字，金句 ≤14 字，正文每段 ≤20 字
- [ ] 深度卡的证据块、意译和“我的判断”已分层
- [ ] 眉题含具体事件日期，不使用只有年月的模糊表达
- [ ] 底部只有 `@spsz0831`
- [ ] 没有 slogan、“一家之言”“个人整理”等多余落款
- [ ] 图片文字没有试图承载完整文章，长内容已移到配套推文
- [ ] 如有真实产品参考图，主体外观与参考图一致
- [ ] 参考图中的无关文字、Logo 和界面没有被错误复制

## B. 语言与推文

- [ ] 使用全角中文标点：，。、：；“”「」——
- [ ] 没有把计划写成已完成，把推测写成事实
- [ ] 推文 ≤100 字
- [ ] 推文不重复卡片正文，补充观点、背景或讨论问题
- [ ] 推文没有未经核验的绝对断言
- [ ] 已按需生成图片 Alt Text 和评论区引导语

## C. Prompt

- [ ] 只拼接一次完整 Prompt 前缀
- [ ] 模式、卡片类型、主题插图、文字内容和落款都已填充
- [ ] 没有虚构模型、分辨率、4K、PNG 或无水印结果
- [ ] 指定 3:4 竖版时，工具确实支持或已说明实际降级
- [ ] Prompt 要求文字清晰、无乱码、无裁切、无重叠
- [ ] Prompt 明确插图约占 55–65%，文字区约占 35–45%
- [ ] Prompt 明确插图要有主体、前中后景、光影、材质和动态配色
- [ ] Prompt 明确不生成无关文字、假 Logo、假 UI、乱码或 emoji
- [ ] 有参考图时，Prompt 明确主体结构、材质和关键外观必须保持

## D. 图片审核

- [ ] 主题插画与素材相关，色彩丰富，风格统一
- [ ] 插画有明确主体、空间层次、光影和材质，不是空白或单色背景
- [ ] 插画占画面主体，文字区没有反客为主
- [ ] 主标题最大、最醒目，文字区层次清楚
- [ ] 没有乱码、缺字、方框或英文标点替换
- [ ] 没有溢出、裁切、重叠或底部文字被遮挡
- [ ] 背景实心、无意外透明、无明显渐变或脏边
- [ ] `@spsz0831` 拼写正确且位于右下角
- [ ] 手机屏幕缩小查看仍然可读

## E. 输出前确认

- [ ] 已说明当前模式：draft / prompt / generate / review
- [ ] 已说明是否完成事实核验
- [ ] generate 模式确实完成图片生成；否则明确降级为 prompt
- [ ] review 模式给出问题、严重程度和最小修改建议
- [ ] Alt Text 能描述主体、事件和关键视觉信息，不是重复标题
