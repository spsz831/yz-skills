# x-spsz 生成前后自检清单

## 📋 生成前检查(8 项 — 内容侧)

### C1. 主标题不能搬运素材原文
- [ ] 主标题是**重写 / 钩子化 / 有反转**,不是素材原句节选
- [ ] 主标题字数 ≤ 12 字(4K 下不溢出)
- [ ] 主标题包含对比 / 反差 / 视角钩子

### C2. 证据块必须标 [原文] / [意译]
- [ ] 证据块 1 显式标注 `[原文]` 或 `[意译]`
- [ ] 证据块 2 显式标注 `[原文]` 或 `[意译]`
- [ ] 标注准确(原话未改=原文,改写/概括=意译)

### C3. 我的判断必须 ≥ 3 行
- [ ] 不是"原文摘要"
- [ ] 有作者视角、有自己的解读
- [ ] 项目符号列出,每行 ≤ 30 字

### C4. 收束金句必须自写
- [ ] 不是素材原话
- [ ] 有反转 / 重音 / 出人意料
- [ ] ≤ 18 字

### C5. 页脚只放 @spsz0831
- [ ] 不写 slogan
- [ ] 不写"一家之言"、"个人整理"、"看大佬调档"等
- [ ] 不写"XX 整理"、"XX 编辑"

### C6. 9 段结构完整
- [ ] 眉题 / 主标题 / 副标题 / 证据块1 / 证据块2 / 我的判断 / 收束金句 / 留白 / @ID
- [ ] 顺序不能乱

### C7. 全角中文标点
- [ ] , 而不是 ,
- [ ] 。 而不是 .
- [ ] "" 而不是 ""
- [ ] —— 而不是 --

### C8. 主题不限定"大佬"
- [ ] 可用于:采访 / 新闻 / 演讲 / 时间点对比 / 任何个人想解读的内容
- [ ] 不是"必须是大佬观点"

## 🛠 GPT Image 2 工具侧检查(5 项)

### T1. 模型正确
- [ ] ChatGPT 端确实选了 **GPT Image 2**(不是 DALL·E 3,不是 gpt-image-1)

### T2. prompt 前缀发送完整
- [ ] §6 整段前缀已拼到正文前
- [ ] 配色 / 字阶 / 必做项都包含

### T3. 比例 + 质量设置正确
- [ ] 3:4 比例
- [ ] 4K 输出
- [ ] PNG 格式
- [ ] 无水印

### T4. 失败回滚预案
- [ ] 翻车时(乱码/溢出/英文标点)→ 回到 §6 前缀,显式强调"中文标点"
- [ ] 翻车时(字体缺字)→ 显式加 "Noto Serif SC / Noto Sans SC"
- [ ] 翻车时(@ID 太大)→ 显式加 "52pt 极小"

### T5. 多次生成版本记录
- [ ] 每次生图保留 prompt + 版本号 + 翻车点 + 修复方式
- [ ] 沉淀到 examples/ 目录

## 🚨 隐藏风险提示

| 风险 | 触发场景 | 应对 |
|---|---|---|
| ChatGPT 端未升到 GPT Image 2 | 模型列表里只看到 DALL·E 3 | 提醒用户升级或换账号 |
| 中文标点被英文覆盖 | 默认行为 | 显式列在 prompt 必做项 |
| 4K 输出被默认 1024×1024 覆盖 | 没勾质量选项 | 显式写"4K, 3072×4096" |
| 主标题太短显得空 | 字数 < 6 | 加副标题补语境 |
| 收束金句过长溢出 | > 18 字 | 砍掉修饰,留主干 |
| "我的判断"被当成"原文摘要" | AI 自行压缩素材 | 显式要求"作者视角 + ≥ 3 行" |
| @ID 写错 / 多写 | 手抖 | 全文 grep `@spsz0831` |
| slogan 偷偷加回来 | 旧 prompt 残留 | C5 + V5 双重检查 |
