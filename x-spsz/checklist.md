# x-spsz 生成前后自检清单

## 📋 生成前检查（6 项 — 内容侧）

### C1. 主标题不能搬运素材原文
- [ ] 主标题是重写 / 钩子化 / 有反差，不是素材原句节选
- [ ] 主标题字数 ≤ 10 字
- [ ] 主标题包含对比 / 反差 / 视角钩子

### C2. 金句必须自写
- [ ] 不是素材原话
- [ ] 有反转 / 重音 / 出人意料
- [ ] ≤ 14 字

### C3. 正文密度克制
- [ ] 每段 ≤ 20 字
- [ ] 最多 3 段
- [ ] 全卡总字数 60-90 字

### C4. 页脚只放 @spsz0831
- [ ] 不写 slogan
- [ ] 不写"一家之言"、"个人整理"、"看大佬调档"等
- [ ] 不写"XX 整理"、"XX 编辑"

### C5. 5 段结构完整
- [ ] 眉题 / 主标题 / 正文 / 收束金句 / @ID
- [ ] 顺序不能乱

### C6. 全角中文标点
- [ ] ，而不是 ,
- [ ] 。而不是 .
- [ ] "" 而不是 ""
- [ ] —— 而不是 --

## 📋 生成后检查（5 项 — 图侧）

### V1. 5 段结构在图上清晰可辨
- [ ] 主标题最大、最醒目、金色
- [ ] 金句次大、金色
- [ ] 正文白色，字号明显小于主标题
- [ ] @ID 极小、右下角

### V2. 文字无乱码
- [ ] 没有 □ 方框
- [ ] 没有缺失字符
- [ ] 中文显示正常

### V3. 标点正确
- [ ] 引号是中文 "" 或「」
- [ ] 破折号是中文 ——
- [ ] 逗号句号是全角

### V4. 无溢出 / 无裁切
- [ ] 所有文字在安全边距内
- [ ] 没有字体重叠
- [ ] 没有被裁掉一半的字

### V5. 页脚确认
- [ ] 只显示 @spsz0831
- [ ] 没有 slogan / 没有"一家之言"等

## 📋 推文文案检查（3 项）

### T1. 推文文案已同步产出
- [ ] 输出了 100 字以内的短推文文案
- [ ] 语气口语化，像人在说话
- [ ] 可与话题标签搭配（可选）

### T2. 推文与卡片互补不重复
- [ ] 推文不是把卡片文字照搬一遍
- [ ] 推文补充了观点、问题或讨论引子

### T3. 事实表述有分寸
- [ ] 报道数字标为"计划/目标/据报"而非绝对断言
- [ ] 未发生的事不用完成时态描述

## 🚨 隐藏风险提示

| 风险 | 触发场景 | 应对 |
|---|---|---|
| ChatGPT 端未升到 GPT Image 2 | 模型列表里只看到 DALL·E 3 | 提醒用户升级或换账号 |
| 中文标点被英文覆盖 | 默认行为 | 显式列在 prompt 必做项 |
| 4K 输出被默认 1024×1024 覆盖 | 没勾质量选项 | 显式写"4K，3072×4096" |
| 主标题太短显得空 | 字数 < 6 | 加正文补语境 |
| 金句过长溢出 | > 14 字 | 砍掉修饰，留主干 |
| 正文堆太多 | 超 3 段或总字数 > 90 | 删减到核心一句 |
| @ID 写错 / 多写 | 手抖 | 全文 grep `@spsz0831` |
| slogan 偷偷加回来 | 旧版本残留 | C4 + V5 双重检查 |
