# x-spsz 完整生图 Prompt 模板

这是一个完整 Prompt。只复制一次，并替换所有 `[填写]` 内容；不要再额外拼接第二份前缀。

```text
请将下面的中文内容制作成一张适合 X（Twitter）发布的彩色主题插画卡片。

【输出规格】
- 竖版 3:4。
- 优先使用当前工具可用的最高质量设置。
- 如果无法精确输出 3072×4096、4K 或 PNG，不要伪造结果，使用实际支持的最佳规格。
- 画面适合手机阅读，文字清晰、完整、无乱码。

【整体风格】
- 这是“插画主导、文字辅助”的视觉卡片，不是密集文字海报或纯信息表格。
- 主题插画占画面约 55–65%，文字区约 35–45%。
- 使用丰富、协调、有层次的彩色编辑插画或电影感场景；根据主题动态选择配色。
- 插画必须有明确主体、前中后景、空间层次、光影、材质和视觉隐喻。
- 颜色要鲜明但不脏乱，避免灰度、单色、空白背景、廉价渐变、随机图标和 emoji。
- 文字区可使用半透明色块、纸张质感、渐变暗部或留白承托文字，但不能遮住插画主体。
- 主标题和收束金句使用高对比色，正文保持清晰易读。
- 背景与文字区可参考米白暖色 #FAF6F0，但不要压制主题插画的丰富色彩。
- 分隔线可参考浅金 #D1C4A9，不要做成生硬的上下两块拼贴。
- 中文字体优先使用思源宋体 / Noto Serif SC 与思源黑体 / Noto Sans SC。
- 不使用 emoji 图标、抽象几何或随机装饰作为主题插图。

【排版要求】
- 以与素材相关的彩色主题插画作为视觉主体，占画面约 55–65%。
- 插画内部不要出现无关文字、假 Logo、假 UI、乱码或装饰性字母。
- 插画与文字区之间自然过渡，不挤压文字，不遮挡文字。
- 保留安全边距，避免裁切、重叠和底部拥挤。
- 所有中文标点使用全角：，。、：；“”「」——。
- 不添加 slogan、“一家之言”“个人整理”或其他落款。
- 底部右下角只放 @spsz0831。

【本次模式】
[填写：标准卡 / 深度卡]

【事件日期】
[填写：事件发生日或官方发布日期，必须为 YYYY年M月D日；多日事件写 YYYY年M月D日—M月D日]

【主题插图】
[填写：主体、场景、前后景、动态、色彩、光影、材质和视觉隐喻]

【眉题】
[填写主题 · YYYY年M月D日。不得只写“2026年9月”“近日”或“今天”]

【主标题】
[填写：标准卡不超过 10 字；必须有视角、对比或反差]

【正文区块】
[填写正文。标准卡最多 3 段，每段不超过 20 字；深度卡可加入证据块]

【收束金句】
[填写：自写、口语化、有重音或反转；标准卡不超过 14 字]

【底部落款】
@spsz0831

【生成后检查】
- 中文文字没有乱码、方框、缺字或错误替换。
- 没有文字溢出、裁切或重叠。
- 主题插画丰富、彩色、有场景层次，且与素材相关。
- 画面不是灰度图、空白模板或密集文字页。
- 插画没有无关文字、假 Logo、假 UI 或乱码，且没有压缩文字区。
- 背景是实心米白，不是透明、纯白或脏边。
- 底部只显示 @spsz0831。
```

## 使用方式

1. 选择标准卡或深度卡。
2. 替换全部 `[填写]` 内容。
3. 生成前运行 `checklist.md` 的 A–C 项。
4. 生成后运行 D–E 项。

如果当前 Codex 已提供图像生成能力，优先直接生成；只有用户要求“给我 Prompt”或工具不可用时，才输出本模板。
