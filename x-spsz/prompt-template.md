## 🔁 复用说明

1. 复制整段到 ChatGPT 网页端对话框
2. 替换所有 `[FILL:...]` 占位符
3. 检查每条证据块是否标注了 [原文] 或 [意译]
4. 检查主标题、收束金句不是素材原话
5. 提交生成

## ⚠️ 常见翻车点

| 翻车 | 原因 | 解决 |
|---|---|---|
| 引号变英文 "" | GPT Image 默认用半角 | 显式要求"中文 "" 「」" |
| 破折号变 -- | 同上 | 显式要求"中文 ——" |
| 出现 □ 方框 | 字体缺字 | 指定 Noto Serif SC / Noto Sans SC |
| 文字溢出 | 4K 下字号偏大 | 主标题 ≤ 12 字,金句 ≤ 18 字 |
| @ID 太大 | 没强调"极小" | 写"右下角,52pt,极小" |
| 出现"一家之言" | 旧版本残留 | 已删除;新版只放 @spsz0831 |
