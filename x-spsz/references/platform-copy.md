# X 与 Threads 双平台文案规则

## X（未开会员）

- 默认输出一条可直接发布的单条内容，不写长线程。
- 先给结论或冲突点，再补 2–3 个具体信息。
- 默认约 100–180 个中文字符，尽量不超过约 280 个字符。
- 话题标签控制在 2–4 个，不用标签堆砌。
- 结尾可以留一个具体问题，但不要强行“欢迎大家讨论”。

## Threads

- 允许更像个人记录，可以多交代一层背景、过程或感受。
- 默认约 180–350 个中文字符，保持短段落和手机可读性。
- 适合加入“我为什么开始”“实际遇到什么”“你会怎么选”等自然表达。
- 仍然只保留一个核心判断，不把 X 版机械扩写成说明书。
- 可使用 2–4 个话题标签；如果正文已经自然，不必强行添加。

## 同一选题的改写规则

| 项目 | X | Threads |
|---|---|---|
| 开头 | 结论、问题或反差 | 场景、经历或疑问 |
| 信息量 | 少而快 | 多一层解释 |
| 语气 | 清楚、利落 | 口语、可聊天 |
| 结尾 | 一个判断或问题 | 一个具体邀请或选择题 |

事实、日期、来源和不确定性必须保持一致；只改变表达，不改变事实。图片通常共用一张，除非平台比例或信息密度明显不合适。配图先服务理解，不为两个平台强行生成两张相似图片。
