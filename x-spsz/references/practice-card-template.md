# HomeServer 实践卡片模板

适用于用户提供自己的部署、设备、截图或失败记录。

## 卡片结构

1. 眉题：`实践记录 · YYYY年M月D日`
2. 主标题：一个具体问题，不写泛泛的“我的 HomeServer 之旅”
3. 设备/工具：只写真实使用的 1–3 项
4. 结果：成功、失败、部分成功或待验证
5. 成本：硬件、订阅、时间、电费，缺失项不要编造
6. 判断：适合谁，不适合谁
7. 底部：`@spsz0831`

## 配套推文结构

```text
我原本想解决：{问题}
实际用了：{设备/工具}
最意外的是：{发现或踩坑}
现在的结论：{推荐、谨慎推荐或不推荐}
```

默认不把实践写成教程大师口吻。没有验证的性能、价格、安全和兼容性，标记为“待验证”。

## 图片方案

- 有真实截图：优先使用截图，插画只做背景或结构说明；
- 有真实设备照片：锁定主体外观，不重新设计设备；
- 没有图片：使用温暖的家庭工作台、迷你主机、硬盘、网线和显示器场景；
- 失败记录：用“现象 → 排查 → 修复”的三段式信息图；
- 工具推荐：用“问题 → 工具 → 结果”的三色块结构。
