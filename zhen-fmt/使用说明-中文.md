# zhen-fmt 使用说明

这份说明书只写一件事：
你平时在 Codex 里，怎么用中文直接让 `zhen-fmt` 帮你基于参考图生图。

## 现在这个 skill 是干嘛的

`zhen-fmt` 现在不是“封面图系统”了。

它现在是一个：

- 基于固定参考图
- 保留同一位 heroine 身份感
- 用你的中文描述去生成新场景、新氛围、新动作、新穿搭

的个人风格生图 skill。

核心就两件事：

- 参考图决定“是谁”
- 你的中文需求决定“这次她在什么场景、什么状态、什么气氛里”

## 你平时怎么直接对 Codex 说

你不需要先想命令。
先直接说中文。

最常见的说法：

- `生成一个安静夜景中的个人风格插画`
- `生成一张个人风格图片`
- `按这张参考图，做一张黄昏城市天台场景`
- `用这个角色生成一张雨后街道氛围图`
- `给我一张偏冷色、克制、安静的个人风格图`
- `先只出 prompt，不要真正生成图片`
- `同一个需求给我 3 个版本`
- `这次固定 seed，我后面还要复现`
- `这次换一张新的参考图`

Codex 背后主要会落到这些参数：

- `-Request`
- `-ConfirmPromptChoice`
- `-ReferenceImage`
- `-PromptOnly`
- `-Variants`
- `-Seed`

## 最常用的 5 种说法

### 1. 需求已经明确时，直接生成 3 张图

你说：

`生成一个安静夜景中的个人风格插画`

对应命令：

```powershell
powershell -ExecutionPolicy Bypass -File ".\skill\scripts\generate-image.ps1" -Request "生成一个安静夜景中的个人风格插画"
```

### 2. 需求比较模糊时，先让它给你 3 个方向

你说：

`生成一张个人风格图片`

对应命令：

```powershell
powershell -ExecutionPolicy Bypass -File ".\skill\scripts\generate-image.ps1" -Request "生成一张个人风格图片"
```

这时它会先给你 3 组中文方向，而不是立刻出图。

### 3. 选定方向后，再一次性生成 3 张

你说：

`选 2，正式生成`

对应命令：

```powershell
powershell -ExecutionPolicy Bypass -File ".\skill\scripts\generate-image.ps1" -Request "生成一张个人风格图片" -ConfirmPromptChoice 2
```

### 4. 只出 prompt，不真正生图

你说：

`先别生成图片，只给我 prompt`

对应命令：

```powershell
powershell -ExecutionPolicy Bypass -File ".\skill\scripts\generate-image.ps1" -Request "生成一个安静夜景中的个人风格插画" -PromptOnly
```

### 5. 固定 seed，方便复现

你说：

`这次固定 seed，后面我要复现`

对应命令：

```powershell
powershell -ExecutionPolicy Bypass -File ".\skill\scripts\generate-image.ps1" -Request "生成一个雨后夜景插画" -Seed "scene-2026-04-25"
```

## 什么时候你该补一句

平时最省事的方式就是只说需求本身，比如：

`生成一个安静夜景中的个人风格插画`

如果你说得很模糊，比如：

`生成一张个人风格图片`

它现在会先给你 3 个中文方向让你选。

只有下面几种情况，才建议你多补一句：

- 想只看 prompt
- 想一次出多个版本
- 想让结果可复现
- 想换参考图

## 换参考图怎么说

你说：

`这次换成这张人物图来生成`

对应命令：

```powershell
powershell -ExecutionPolicy Bypass -File ".\skill\scripts\generate-image.ps1" -Request "生成一个雨后夜景插画" -ReferenceImage "E:\你的路径\新参考图.jpg"
```

## 你可以直接复制用的中文模板

普通场景：

`生成一个安静夜景中的个人风格插画`

偏氛围：

`生成一张偏冷色、克制、安静的个人风格图`

偏场景：

`按这张参考图，生成一个黄昏城市露台场景`

偏情绪：

`用这个角色生成一张有点疏离感的夜晚氛围图`

只出 prompt：

`先不要生图，只给我 prompt`

多个版本：

`选 2，正式生成`

固定 seed：

`这次固定 seed，后面我要复现`

换参考图：

`这次用这张新的参考图来生成`

## 最短工作流

如果你只记一个最短工作流，就记这个：

1. 如果需求明确，直接说：`生成一个安静夜景中的个人风格插画`
2. 如果需求模糊，先说：`生成一张个人风格图片`
3. 它给你 3 个方向后，你再说：`选 2，正式生成`
4. 如果想先研究文案，再说：`先不要生图，只给我 prompt`
5. 如果想以后复现，再说：`顺便固定一个 seed`

这就够你日常用了。
